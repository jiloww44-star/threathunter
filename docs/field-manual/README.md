# ThreatHunter360 Field Manual — Operator Drills (v3.5, red-team #1)

Automation bias and skill atrophy are product risks, not user failings: a
tool that always answers removes the operator's need to think. These short
drills keep the skills the platform depends on — verification, control, and
sovereignty — exercised. Each runs against the live demo profile, needs no
credentials, and takes under ten minutes.

**The one rule of every drill:** the platform scores nothing here; *you*
judge your own work. The AI's output is the training dummy, never the answer
key.

| # | Drill | Skill exercised | Linked risk |
| --- | --- | --- | --- |
| 01 | [Spot the fabrication](01-spot-the-fabrication.md) | Verifying AI claims against raw evidence | automation bias |
| 02 | [Halt the swarm](02-halt-the-swarm.md) | Operator control mid-execution | unstoppable automation |
| 03 | [Withdraw consent](03-consent-withdrawal.md) | Data sovereignty + effective-state reading | silent data use |

Run them in order the first time; after that, 01 monthly keeps the
verification habit honest.
